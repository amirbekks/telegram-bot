# ҚМЖ бот — тарих мұғалімдеріне арналған Telegram бот

Тарих пәні мұғалімдеріне (**Қазақстан тарихы**, **Дүниежүзі тарихы**, 5–11 сынып)
қазақ тілінде **ҚМЖ (қысқа мерзімді жоспар)** дайындайтын **жабық (ақылы)** бот.

Бот сілтемесі тарих мұғалімдерінің чаттарына таратуға арналған. Генерация тек
белсенді тарифі бар қолданушыларға қолжетімді.

## Тарифтер

| Тариф | Баға | Мүмкіндіктер |
|-------|------|--------------|
| 🥉 Бастауыш | 2 990 ₸/ай | ҚМЖ қаңқасы, 15 ҚМЖ/ай |
| 🥈 Стандарт | 5 990 ₸/ай | Толық ҚМЖ + мақсаттар/критерийлер, Word (.docx), 50 ҚМЖ/ай |
| 🥇 Премиум | 9 990 ₸/ай | + слайдтар жоспары, қосымша тапсырмалар, шексіз |

Бағалар мен мүмкіндіктер `config.py` ішінде оңай өзгертіледі.

## Құрылымы

```
bot.py              — іске қосу нүктесі (роутерлерді жинайды)
config.py           — .env айнымалылары және ТАРИФТЕР
database.py         — SQLite (қолданушылар, жазылымдар, лимиттер, өтінімдер)
curriculum.py       — 5–11 сынып тарих тақырыптарының картасы
kmzh_generator.py   — ҚМЖ генераторы (мәтін + .docx), тарифке қарай тереңдік
keyboards.py        — батырмалар (reply + inline)
handlers/
  user.py           — /start, тарифтер, ҚМЖ құру, жазылым
  admin.py          — әкімші панелі, доступ беру, өтінімдер, тарату
```

## Іске қосу

```bash
pip install -r requirements.txt
cp .env.example .env     # BOT_TOKEN және ADMIN_ID толтырыңыз
python bot.py
```

## Әкімші командалары

- `/admin` — панель + статистика
- `/users` — соңғы қолданушылар
- `/requests` — жаңа өтінімдер
- `/grant <user_id> <tier> [days]` — тариф беру (`days=0` → мерзімсіз)
- `/revoke <user_id>` — доступты алу
- `/broadcast` — барлығына хабарлама

Қолданушы «💳 Тарифтер» → жазылымды таңдап өтінім жібергенде, әкімшіге
батырмалары бар хабарлама келеді (бір рет басумен белсендіру).

## Қалай жұмыс істейді (ағым)

1. `/start` → тіркелу → басты мәзір.
2. «💳 Тарифтер» → тариф таңдау → өтінім → әкімші белсендіреді.
3. «📝 ҚМЖ құру» → пән → сынып → тақырып (тізімнен не қолмен).
4. Бот ҚМЖ мәтінін (және тарифке қарай Word файлын) жібереді.

## Келесі қадамдар (негіз дайын, кеңейтуге болады)

- **ИИ-генерация**: `kmzh_generator.build_sections()` — LLM жауабымен ауыстыруға
  дайын нүкте (мәтін/.docx рендері сол күйінде қалады).
- **Telegram Payments**: қазір белсендіру қолмен (әкімші). Автоматты төлемді
  қосуға болады.
- **Презентация файлы**: қазір слайдтар жоспары мәтінмен. `.pptx` экспортын қосуға болады.
- Тақырыптар картасын (`curriculum.py`) оқу бағдарламасына толық сәйкестендіру.
